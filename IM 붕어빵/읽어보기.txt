IM  DECALCOMANIA
================

원본 IM(PDF) 을 **생긴 그대로** PPT 로 찍어 낸다. 접었다 펴면 똑같이 찍히는 데칼코마니처럼.
바꾸는 것은 글꼴(피플폰트 Light/Bold 10pt) 과 색(표 머리글 남색 #08377C / 테두리 #A5A5A5 0.5pt) 뿐,
칸 자리·줄바꿈·그림은 원본 그대로 둔다.


■ 쓰는 법

   맨 위의  [IM 붕어빵 열기.bat]  을 더블클릭한다.
   → 프로그램이 켜지고 브라우저가 열린다(처음엔 10~20초).
   → PDF 를 올리면 알아서 변환되고, 버튼을 누르면 PPT 를 받는다.

   자주 쓸 거면 그 파일을 우클릭 → '바로 가기 만들기' 해서 바탕화면에 두면 편하다.


■ 어디에 있나

   자동화\IM\IM 붕어빵\   ← 이 폴더 하나뿐이다. 여기 코드가 곧 웹에 올라가는 코드다.

   ★2026-10-06 작업실(_IM 붕어빵)과 웹 사본(decalco)을 이 폴더 하나로 합쳤다.
     이제 '통합에 반영' 같은 복사 단계가 없다. 여기서 고치고 push 하면 끝.
   ★검사에 쓰는 IM 원본은 자동화\IM\IM(샘플)\ 에 모여 있다(다른 IM 도구와 같이 쓴다).


■ 폴더 구성

   IM 붕어빵 열기.bat   ← 이것만 누르면 된다

   app.py               화면(업로드 → 변환 → 내려받기)
   pdf_to_ppt.py        변환 엔진. 고칠 일이 있으면 거의 다 여기다
   fonts\               피플폰트

   검사도구\            고친 뒤 확인할 때만 쓴다
      _전체검사.py      ★IM(샘플) 폴더의 IM 을 전부 돌려 숫자로 비교한다. 제일 중요
      _전체보기.py      한 문서를 전 쪽 변환해 원본과 나란히 그림으로 뽑는다
                        쓰기: python _전체보기.py "원본.pdf" "내보낼폴더"
      _높이검사.py      표가 원본보다 세로로 늘어나지 않았는지 잰다
      _선검사.py        원본 선과 표 테두리를 좌표로 맞대본다
      _정렬검사.py      표 칸 글자가 원본 자리에 놓이는지 잰다
      _색검사.py        원본 표에 실제로 어떤 색이 칠해져 있는지 센다
      _확인하기.py      몇 쪽만 빠르게 그림으로 뽑아 본다
      _다른원본검사.py  아무 IM PDF 나 넣어서 검사 + 대조를 한 번에
      _뜯어보기.py      원본 글자 조각이 어떻게 쪼개져 있는지 뜯어본다

   자료\
      _검사표.txt       마지막 검사 결과. 고치기 전 상태와 견주는 기준이다
                        (웹에는 안 올라간다)
   (검사용 원본 → 자동화\IM\IM(샘플)\. 새 IM 을 받으면 거기 넣기만 하면
    자동으로 검사 대상에 들어온다.)

   실패작\              예전 실패 버전들(무엇이 어떻게 틀렸는지 기록, 웹에는 안 올라간다)
   읽어보기.txt         이 글


■ 고칠 때 지킬 것

   1) 한 문서만 보고 기준값을 정하지 말 것.
      반드시 검사도구\_전체검사.py 로 전부 확인한다.
      _검사표.txt 보다 하나라도 나빠지면 되돌린다.

   2) 눈으로 안 보이는 게 있다.
      표가 하나로 연결됐는지는 그림으로는 절대 모른다(겉모습이 똑같다).
      _전체검사.py 의 '안쪽표' 숫자로 확인할 것.

   3) 원인을 추측하지 말고 실제로 재 볼 것.

   4) .bat 파일 안에는 한글을 쓰지 말 것(cmd 가 깨뜨린다). 줄바꿈은 CRLF.
      한글은 파일 '이름' 에만.
