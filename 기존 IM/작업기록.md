## 1. 이 앱이 하는 일

**rainfield-im** — IM(투자설명서) PDF를 회사 템플릿 PPT 제안서로 변환하는 Streamlit 웹앱.
- 배포: `git push` → Streamlit Cloud 자동 반영 (github.com/rainfieldinv-cell/rainfield-im)
- 배포 직후 화면에 `removeChild` 빨간 에러가 잠깐 뜰 수 있음 → **탭 닫았다 다시 열면** 사라짐(정상, 코드 문제 아님).

---

## 2. 단계 흐름 (현재 6단계)

| 단계 | 이름 | 하는 일 |
|---|---|---|
| 1 | 파일 업로드 | PDF(우선)/워드 업로드 → 텍스트·이미지·페이지 추출, 사업명 입력 |
| 2 | 하이라이트 구성 | Executive Summary 카드 3개 입력 + **완성본 미리보기(체크박스)** |
| 3 | 목차 구성 | 원본 페이지 보며 목차·소제목 작성, **소제목마다 원본 페이지 번호 지정** |
| 4 | 배치 확인 | 소제목별로 넣은 원본 페이지를 순서대로 이미지 확인·수정 |
| 5 | 레이아웃 선택 | 날짜·표지/목차/섹션 이미지 지정 + **표지·목차·섹션 미리보기(체크박스)** |
| 6 | 전체 PPT 생성 | 최종 PPT 생성·다운로드 |

- 생성은 **3단계 목차·페이지 배치 순서 그대로** 본문을 만든다.
- 1.1 본건 사모사채 개요 / 2.1 금융 구조도는 **항상 자동 생성**(원본 페이지 불필요, "고정" 체크).

## 3. 이번 세션에서 고친 것 (모두 배포됨)

1. **[치명적] 내용이 통째로 사라지던 버그** — 표 추출이 특정 페이지에서 실패하면 파싱 전체가
   죽어 본문이 하나도 안 나오던 문제. 페이지별 try/except 안전장치로 해결.
2. **표 위주 페이지 살리기** — 글자 적고 표가 핵심인 페이지(거래사례·민감도·비교표 등)가
   버려지던 것 → 표 추출을 '내용 부족' 판단보다 먼저 하여 유지.
3. **목차 오인식 방지** — 본문에 '목차/contents' 단어만 있어도 스킵되던 것 → 맨 위 3줄에
   있을 때만 목차 페이지로 판단.
4. **각주(`*) 주N) 1)`)를 그 표 바로 밑에** 붙이도록 — 맨 마지막 표에 몰리거나 여러 표
   각주가 합쳐지던 것 수정.
5. **사진 개수 캡 제거** — "1장/2장만" 제한을 없애 **그 페이지 사진 전부** 배치.
6. **비교/사례표 중앙정렬** (거래사례·민감도·Cap Rate 등).
7. **글씨 겹침 완화** — 글상자 높이 추정을 글자별 실제 폭(한글 1em/영문 0.5em)으로 교정.
8. **단계 개편** — 7단계 → 6단계. '하이라이트 완성본' 별도 단계 삭제 → 2단계 미리보기로.
   레이아웃 미리보기는 버튼 → 체크박스 인라인. 목차 단계의 소제목 미리보기 제거(배치확인이 대체).

되돌린(취소한) 것: '목차·배치 파일 저장/불러오기' 기능 — 원인 오진이라 revert함.

## 4. 아직 안 끝난 것 (다음에 할 일)

렌더링 미세 조정 5가지(사용자 지적):
1. 각주 `1)` 누락 (어떤 표에서 1)이 빠지고 2)만 나옴) — **합성 테스트에선 재현 안 됨**(정상 나옴).
2. 같은 3문장이 표 밑에 2번 중복.
3. 옆으로 나란한 2개 표의 세로 높이 맞추기.
4. 시공사 Track Record: 조감도 8개인데 1개만 나옴.
5. 엉뚱한 표(선임차 확보물량/임차마케팅)가 없어야 할 페이지에 나타남.

> 이 5개는 **사용자 실제 문서 구조에 달린 문제**라, 정확히 고치려면 그 IM PDF로
> 직접 생성→렌더 확인이 필요하다. 아래 5번 참고.

## 5. 로컬에서 결과를 '눈으로' 확인하는 법 (중요 도구)

이 PC엔 LibreOffice는 없지만 **PowerPoint + pywin32** 가 있어서, 만든 PPTX를
슬라이드 이미지(PNG)로 뽑아 직접 확인할 수 있다.

```bash
# 1) 테스트 덱 생성 후 이미지로 뽑기
python _render_pptx.py <만든.pptx> _render_out 1 10
# → _render_out/slide_01.png ... 을 열어서 렌더 결과 확인
```

- `_render_pptx.py` : PPTX → 슬라이드별 PNG (PowerPoint COM 자동화). 로컬 검증 전용.
- 앞으로 렌더링 고칠 때는 **반드시 이걸로 뽑아서 눈으로 확인 후** 배포할 것(장님 수정 금지).
